# 📅 Phonk Timeline

A chronological overview of notable Phonk releases and important periods in the genre's evolution.

> **Important:** A track appearing in a playlist does not necessarily mean it was originally released in that year. This timeline focuses on the original release era where known, while the **Current Scene** section tracks newer discoveries and playlist activity.

---

## 🎵 2020 — Modern Phonk Emerges

The early 2020s saw Phonk move increasingly toward the aggressive, bass-heavy sound that would later become strongly associated with Drift Phonk.

### Notable Releases / Artists

* *DVRST* — "Close Eyes"
* *Kordhell* — "Murder In My Mind"
* *Pharmacist* — "North Memphis"
* *DJ Smokey* — "Evil Wayz"
* *Soudiere* — "High As Hell"

**Key developments:**

* Growth of internet-based Phonk communities
* Revival of Memphis-inspired samples
* Increased use of distorted 808s
* Rise of cowbell-led melodies
* Early development of modern Drift Phonk aesthetics

---

## 🎵 2021 — Drift Phonk Explosion

Drift-oriented production became increasingly recognizable through aggressive basslines, cowbells, distorted drums, and dark Memphis-inspired vocals.

### Notable Tracks

* *DVRST* — "Close Eyes"
* *Hensonn* — "Sahara"
* *MoonDeity* — "NEON BLADE"
* *INTERWORLD* — "METAMORPHOSIS"

**Key developments:**

* Drift Phonk becomes strongly associated with car/drifting edits
* Short-form video platforms accelerate Phonk discovery
* Dark atmospheric synths become increasingly common
* Cowbell melodies become a defining modern Phonk sound

---

# 📖 Glossary of Terms

### 🔔 808 Cowbell

The distinctive cowbell sound associated with the Roland TR-808 drum machine. Modern Phonk frequently uses heavily processed or pitch-shifted cowbells as melodic elements.

### 🎤 Memphis Rap Vocals

Vocal samples influenced by 1990s Memphis underground hip-hop.

Commonly associated artists include:

* Three 6 Mafia
* Tommy Wright III
* Koopsta Knicca
* Kingpin Skinny Pimp
* DJ Zirk

### 🔪 Chopped & Screwed

A production technique associated with DJ Screw involving slowed-down audio, chopped sections, repetition, and pitch manipulation.

### 🎙️ Phonk Acapellas

Isolated or sampled vocal recordings commonly processed with:

* Pitch shifting
* Distortion
* Reverb
* Delay
* Telephone filtering
* Tape effects

### 🔊 Distorted 808

A heavily saturated or clipped bass sound used extensively in modern Drift and Brazilian Phonk.

### 🥁 Montagem

A Brazilian music production approach associated with heavily edited and repetitive vocal and rhythmic elements, particularly within Funk-related scenes.

### 🏎️ Drift Phonk

A modern Phonk style strongly associated with aggressive bass, cowbells, Memphis-inspired samples, and car/drifting edits.

### 🌐 Internet Phonk

A broad modern category describing Phonk influenced heavily by online communities, short-form video culture, electronic production, and remix culture.

If you're looking for newer releases, don't only search for the word **Phonk**.

```text

Montagem

Drift Phonk
Aura Phonk
Internet Phonk
Rare Phonk
Memphis Phonk
Wave Phonk
Phonk House
Underground Phonk
Phonk Edit
```

### Search by Artist

Discover related artists by checking:

* Spotify artist radio
* YouTube recommendations
* SoundCloud related tracks
* Bandcamp tags
* Reddit discussions
* Producer Discords

### Search by Track

When you find a good track:

1. Check its producer.
2. Check the producer's other releases.
3. Check related artists.
4. Check the label.
5. Check remixes and collaborations.
6. Check the track's playlist appearances.
7. Search for similar releases from the same month/year.

# 🤝 Contribution Guide

Contributions are welcome!

If you know a great Phonk track, producer, resource, playlist, community, or open-source project that is missing, feel free to contribute.

### 1. Fork the Repository

```bash
git clone https://github.com/YOUR_USERNAME/awesome-phonk-finder.git
```

### 2. Create a Branch

```bash
git checkout -b feature/add-phonk
```

### 3. Add Your Contribution

Examples:

* New track
* New artist
* New subgenre
* New producer resource
* New GitHub project
* New playlist
* New community

### 4. Commit Your Changes

```bash
git add .
git commit -m "Add new Phonk releases"
```

### 5. Push Your Branch

```bash
git push origin feature/add-phonk
```

### 6. Open a Pull Request

Please provide:

* Correct artist name
* Correct track title
* Original release year when known
* Subgenre/style
* Short description
* Valid source/link

# 🔄 Keeping the Repository Updated

The Phonk scene changes quickly.

The repository should therefore distinguish between:

### 📅 Original Release

When the track was originally released.

### 🔥 Discovery Year

When the track became widely discovered or experienced a major resurgence.

### 🆕 Current Scene

Tracks currently appearing in new releases and discovery playlists.

This prevents older tracks from being incorrectly classified as new simply because they became popular again.
