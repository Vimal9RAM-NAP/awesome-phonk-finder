# Contributing to Awesome Phonk Finder 🔊

First off, thank you for considering contributing to **Awesome Phonk Finder**! It's community members like you that make this directory a rich resource for the Phonk community.

Please take a moment to review these guidelines before submitting a Pull Request.

---

## How Can I Contribute?

### 1. Adding a New Track or Subgenre
When adding a new track, subgenre, or streaming source:
* **Subgenres:** Must include BPM range, key musical characteristics, and at least 3 definitive track examples.
* **Tracks:** Use the format `*Artist Name* – "Track Title"` and ensure it accurately represents the target subgenre.
* **Formatting:** Maintain alphabetical order where applicable and check for existing duplicate entries before opening a PR.

### 2. Adding Producer Resources or Tools
* Links must point directly to safe, legal, or open-source repositories/tools (e.g., GitHub, official VST sites, public domain sample vaults).
* Do **not** submit links to copyrighted software, pirated sample packs, or unsafe download mirrors.

---

## Pull Request Guidelines

1. **Fork the Repo:** Create a fork of `Vimal9RAM-NAP/awesome-phonk-finder`.
2. **Branch Naming:** Use descriptive branch names like `feat/add-phonk-house` or `fix/broken-spotify-links`.
3. **Commit Messages:** Write clear, concise commit messages (e.g., `feat: add Phonk House subgenre and definitive tracks`).
4. **Single Scope:** Keep each Pull Request focused on one specific addition or fix to simplify review.

Thank you for helping build the ultimate Phonk directory! 🎧
